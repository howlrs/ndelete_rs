# README

## 概要
本リポジトリは、複数回の乱数データ上書き後にファイルを削除することで、データの復元を困難にする機能を提供しています。以下の手順で簡単にご利用いただけます。

## 使用方法
1. **パスの入力**  
   - 対象のディレクトリまたはファイルのパスを、絶対パスで入力してください。  
   - 複数のパスを入力する場合は、改行で区切ります。

2. **解析（Analysis）**  
   - 「解析」ボタンをクリックすると、対象ファイルの内容が表示されます。  
   - 必要に応じて削除回数（上書き回数）を指定してください。

3. **削除実行（Delete）**  
   - 解析結果を確認して問題がなければ「削除実行」ボタンをクリックします。  
   - 上書き後にファイルが削除されます。

4. **処理結果の確認**  
   - 削除結果の詳細と、成功または失敗したパスが表示されます。  
   - リザルトファイルに記録され、必要に応じてご参照いただけます。

## 注意事項
- ディレクトリを指定した場合、そのディレクトリ内のファイルが処理対象になりますが、ディレクトリ自体は削除されません。  
- ファイルが削除に失敗した場合は、権限やファイルの状態を確認の上、再度実行してください。  
- 一度削除したファイルは復元がほぼ不可能になるため、対象ファイルをよく確認してから実行してください。
